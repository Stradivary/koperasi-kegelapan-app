Koperasi Kegelapan — High-Level Architecture

Offline-first NFC cooperative payment system on Cloudflare edge

Key Lifecycle Flow

①
Login Online
Terminal authenticates via /auth. Backend issues a signed session grant (Ed25519, 24h TTL) with allowed ops and device binding. Grant is cached in IndexedDB.
②
Go Offline — NFC Read
Terminal reads NTAG215 card. Decrypts AES-256-GCM payload, validates HMAC-SHA256 trailer and chain counter. Rejects tampered or replayed cards.
③
Process Transaction
Applies debit/credit/checkin/checkout to the active A/B buffer. Updates wallet balance, increments chain counter, recomputes HMAC, writes back to card via NFC.
④
Queue to Outbox
Transaction is appended to the reconciliation outbox in IndexedDB with an idempotency key. Terminal continues operating fully offline.
⑤
Back Online — Sync
Service Worker detects connectivity. Outbox batch is POSTed to /sync. Backend deduplicates via idempotency key, persists to D1, updates sync_cursors.
⑥
Reconcile & Audit
Reconcile engine merges A/B buffer, detects conflicts, writes final state to transaction_log and audit_log. Broadcasts card_events via SSE to other terminals.
